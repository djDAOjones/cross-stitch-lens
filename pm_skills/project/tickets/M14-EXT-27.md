# M14-EXT-27 — Trackpad pinch-zoom and two-finger pan

Memo item 11 (fourth look, D106): pinch to zoom, two-finger drag to
pan, "but only have it become sensitive to command when the preview
is clicked into, or some other elegant and UI-directives compliant
solution".

## Outcome

While the canvas host is **engaged**, the trackpad drives the view:
pinch zooms about the pointer, two-finger scroll pans. While it is
not, the preview stays wheel-inert and the page scrolls past it —
today's behaviour, unchanged.

## The engagement answer already exists

D92's **focus-unified panning**: pan engagement *is* canvas-host
focus — click focuses (native), focused host pans, no second mode
machinery. Gestures join the same contract: focused ⇒ armed,
unfocused ⇒ inert. The memo's "clicked into" is exactly this; no new
concept needed.

## Supersession, named

M14-EXT-10 removed the wheel handler entirely and the code says "do
not reintroduce it" (`src/ui/preview.ts:230`). That rule is
**reopened for the engaged state only** (owner authority, D106): the
unfocused surface keeps the M14-EXT-10 promise verbatim. The comment
updates to name the split rather than being silently contradicted.

## Mechanics

- macOS trackpad pinch arrives as `wheel` with `ctrlKey: true`
  (Chrome/Edge/Firefox); Safari also fires `gesturestart/change/end`.
  Two-finger scroll is plain `wheel` with deltas. Map: ctrl-wheel →
  zoom about the cursor anchor; plain wheel → pan by deltas.
- The zoom math survives in `src/ui/viewport.ts` (the wheel-zoom
  anchor contract at `viewport.ts:113` was kept when the handler
  died) — reuse it, don't rewrite it.
- `preventDefault` only while engaged (the handler must be
  non-passive there); never globally, or the page loses scroll.
- Browser pinch-zoom of the page itself must keep working when the
  host is not engaged (AAA: never break user agent zoom).

## Constraints

- Keyboard equivalence stands: +/−/0 zoom, arrow pan already exist —
  gestures are an addition, never the only route (no path-based
  gesture requirement).
- Zoom limits, fit/reset semantics (Reset view, D92) unchanged;
  gesture zoom lands in the same manual-zoom state the buttons use,
  with the same auto-fit release rules.
- Announce nothing per-frame — gesture moves are continuous; the
  existing zoom announcement policy applies at rest, not per event.
- Regression tests: the unfocused-inert contract and the anchor math
  are pure-module testable (`tests/viewport.test.ts`); the live feel
  is ACCEPT-01's.
