# M14-EXT-30 — Appearance becomes Processing; grid controls move out

Memo item 16, the M14-safe half (fourth look, D106). The dithering
*profiles* and their editor are M15-SCOPE-02; what lands here is the
rename and the relocation, so M15 inherits a section that already has
its final name and only dither content.

## Outcome

- The `Appearance` section renames to **"Processing"**.
- The grid geometry controls leave it for a more thematically linked
  home, leaving Processing = the Dither group alone.

## What "grid controls" means here

After M14-EXT-11/D92 the grid **on/off toggles** already live in the
view strip. What remains in Appearance is the geometry behind the
reveal: the `Grid` legend group and the `Grid details` disclosure
(major interval, ticks, numbering — `src/main.ts` ~860–915).

## Destination options

- **A (recommended): the view strip's grid reveal.** The on/off
  toggles live there; same concept, same home (consistency
  heuristic). The strip is deliberately quiet, so the geometry stays
  behind a reveal, not inline.
- **B: the Design section.** Grid geometry as pattern structure —
  defensible, but Design is deliberately slimming (EXT-20 compacts
  Size, EXT-28 removes Colour), and grid lines are a *view* of the
  pattern, not the pattern.
- **C: stay put.** Rejected by the memo ("need to be moved out of
  here").

Pick at the design gate; A unless the strip's reveal turns out to be
too cramped for labelled number inputs at 44 px.

## Constraints

- Rename is text + section id concerns: disclosure persistence keys
  are per-id (`section-appearance`) — decide whether the key migrates
  or resets, and don't strand a stored preference silently.
- The dither select may pre-adopt the label "Dithering profile"
  only if the pick gate says so; behaviour changes are M15's, none
  ship here.
- M11 (grid/ruler/tick styling presets, icebox) is not preempted:
  this is relocation, not preset work.
- The summary line for the renamed section still reads dither state
  until EXT-22 flattens summaries — coordinate wording, don't fight
  the run order.

## Files

`src/main.ts` (section registry, grid group, view strip),
`src/ui/preferences.ts` (disclosure key migration if any),
