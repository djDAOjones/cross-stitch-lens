# M14-EXT-42 — Colour section: compress the redundancy

Memo item 6 (sixth look, D112): "the colour UI has redundancy and
uses a lot of real estate. see if you can improve it."

Runs **after EXT-43** (the dropdown defect) so the compression works
on a correct base — and because 43's fix may restructure the same
`update()` path this task touches.

## The redundancy census (grounded in the live DOM, 2026-08-07)

1. **Seven elements for one integer.** Constrain switch + "Colours"
   slider + "Number of colours" field + Fewer/More stepper buttons +
   "slider reaches 64" helper + two status regions — the EXT-29
   lockstep cluster. Candidates: drop the steppers (⚠ they were the
   owner's own EXT-29 ask — a named reversal, their call); unify the
   two labels; one status region.
2. **Eight near-identical brand helper lines** ("Colours and names as
   supplied for Anchor." ×8) → one shared note above the group.
3. **Summary line vs Stats.** "489 permitted · 8 requested — chosen
   when the design updates." overlaps Stats' "Colours in use — 8 ·
   limit 8" (the no-third-copy duty, EXT-21). Candidate: keep the
   conflicts list (aria-live, load-bearing) and the permitted count
   somewhere honest; drop the requested half (Stats owns it).
4. **Six standing library buttons** (Save as palette · Delete this
   palette · Undo delete · Export inventory · Import inventory ·
   Export palettes) + the storage note → group behind a second-level
   reveal or a tighter row; Undo only needs to exist after a delete.
5. **Two stacked switches** (Threadify colours / Constrain number of
   colours) — different semantics, likely keep; the gate may merge
   their visual rhythm, not their meaning.

## Bounds

- The conflict/explanation pattern (aria-live list, severity as a
  word) is UI-STANDARDS-bound — compress around it, never into it.
- The source select is **M15's future "Colour profile" slot**
  (ui-spec §5) — do not foreclose it; D112 notes the M15 scoping
  sessions may absorb some of this surface later, which argues for
  cheap compression now, not a rebuild.
- Reach contracts hold (§1): nothing E/C-tier may fall below its
  tier; the thread depth stays reach 3.
- 44 px targets, labels = accessible names, both schemes.

## Method

EXT-05/EXT-36 shape scoped to one section: rank, fix
agent-executable compressions, before/after evidence (element count
and pixel height at 380 px and wide) in `docs/ui-evidence.md`, park
what needs the owner (the steppers reversal, anything
M15-overlapping).
