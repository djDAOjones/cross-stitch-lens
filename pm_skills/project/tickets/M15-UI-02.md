# M15-UI-02 — Takeover editor shell (shared)

Scope parent: D114 (takeover view, draft model), D116 (kind
contract), D117 (editor-Save contract). Line compressed into this
ticket at the 2026-08-07 roadmap refactor (D119); full intent
preserved here.

## Anatomy

- The shell is a **view swap, not a dialog**: header with profile
  switcher and New/Duplicate/Rename/Delete, draft model with
  Save/Cancel/Back, focus and a11y anatomy per `UI-STANDARDS.md`.
- A capture session survives underneath the takeover — the editor
  never tears down the session.

## Kind contract (D116)

- Built **profile-kind-agnostic**: the draft is opaque to the shell;
  each kind supplies its form and its stage-override mapping. The
  dither kind (M15-DITH-02) must mount without shell change — that is
  the design goal, and any change it forces anyway is recorded.

## Editor-Save contract (D117 seam fix 2)

- Save on the **design's active profile** updates the design's copy
  in the same act.
- Saving **any other profile** never touches the design.
- M15-DITH-02's "Use" question inherits this settled answer.

## Done when (expanded)

- open→edit→Save/Cancel/Back all keyboard-clean with focus returned.
- Frame results never rebuild editor controls — regression test (the
  EXT-43 contract).
- A second profile kind could mount without shell change.
