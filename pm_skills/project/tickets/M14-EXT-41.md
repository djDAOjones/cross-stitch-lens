# M14-EXT-41 — Colours used: rename and one section hierarchy everywhere

Memo item 3 (sixth look, D111), sic-repaired: "rename 'colours by
usage' to 'Colours used' and give it same hierarchy status as
capture and preview. Stats, design etc should also have the same
hierarchy status as capture and preview."

Runs **after EXT-40** so the equalisation lands on the final section
census (Design gone, the Capture section's final shape settled).

## Diagnosis (what "hierarchy status" differs today)

- **Colours by usage** is not a section at all: it is the info
  panel's `<details>` fold (D99 lineage) — body-compact summary text,
  depth-reveal anatomy, visually a tier below the h2 accordion
  headers of Capture/Preview.
- **Stats/Colour/Processing/…** already share the accordion anatomy
  with Capture/Preview (same `createSection`, same heading tokens) —
  what differs is the **container**: the aside wraps them in a
  layer-01 box with border + padding, so they read as nested inside
  a panel while Capture/Preview sit flat on the page background.

## Options (pick at the gate)

- **A (floor): anatomy equalisation.** The info panel becomes a real
  accordion section — **"Colours used"**, content column, directly
  under Preview where it sits now; `createSection` anatomy, bare
  heading collapsed (EXT-22), spec-default closed (D99's default
  survives the promotion), disclosure persisted with the old
  `colours-table` key seeding the new id by fallback (the EXT-30
  precedent). Aside keeps its box.
- **B (recommended): A + flatten the aside.** The settings column
  drops the layer-01 box/border so every section reads at one
  visual level in both postures — the two-column layout itself is
  untouched (the 16 rem companion architecture is load-bearing,
  D77/M6); only the box goes. Check the section divider rhythm holds
  the column together without the border, both schemes, and that
  `check:contrast` pairs still bind (text moves from layer-01 to
  background — both pairs already in the table).
- C: single-column IA merge (everything in one flow). Rejected as
  recommendation — it unwinds the companion-window layout for a
  hierarchy ask that A/B satisfy; ACCEPT-01 territory if the owner
  means it.

## Naming note (for the gate)

Stats' row is "Colours in use"; the renamed section would be
"Colours used" — near-twins naming different things (a count vs the
table of which). Consistency rule says same words for same concepts
and different words for different ones; these are different concepts
and the near-match may still read as a duplicate. Flag it; owner's
wording stands unless they say otherwise.

## Mechanics

- The table keeps its in-panel horizontal scroll (Reflow rule) inside
  the new section panel; highlight rows keep reach 2 (§1 contract —
  open the section, press the row).
- `info-panel` CSS class stays on the table wrapper; the fold-specific
  summary styling retires with the fold.
- The D103 nothing-scroll-linked rule: the new section is NOT part of
  the sticky preview unit — it scrolls beneath, as the info panel
  does today.
- ui-spec §2 diagram + §5 rows; the D99 decision is superseded in
  part (placement/anatomy — the collapsed-by-default choice
  survives).
