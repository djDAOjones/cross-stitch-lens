# M9 — Symbols and practical chart modes

## Scope signed 2026-08-11 (D160)

The four owner decisions are made; the sitting happened in-session on
the agent's recommendations, accepted whole:

1. **Visual language: app-owned vector shapes.** No font asset, no
   fontkit dependency, one geometry model for the canvas chart and the
   PDF (pdf-lib `drawSvgPath`). A **reviewed set of ~64 glyphs**
   (matching the colour slider's ceiling), drafted and signed in
   batches through the gallery process (D139/D146 precedent), judged at
   print size. Past the set, symbol export **refuses with a clear
   message** — repeating a symbol silently stays banned.
2. **Licence: dissolved by decision 1.** Nothing is embedded, so M9 is
   distribution-independent and **decoupled from ICE-TAURI-01**.
3. **Manual overrides: collisions unrepresentable, not validated.**
   Pick from *unused* symbols only; taking another thread's symbol is
   an explicit swap, never a conflict state. No free-text or arbitrary
   Unicode, ever. The model persists `threadId → symbolId` overrides
   from day one; the override UI is a v1-optional slice.
4. **Persistence: symbols follow identity, never colour, and
   assignment is state, not recomputation.** Keyed on
   `brandId:reference`; a thread present before and after a palette
   change keeps its symbol; reorder and hide cannot move anything.
   First need takes the next unused symbol from the canonical order and
   is **stored in the project file**. Departed threads release to the
   *back* of the queue; dormant overrides stay in the file. Cross-brand
   replacement resets assignments — no RGB-similarity carryover
   (D55/D56). Adjacency/similarity optimisation is out of scope for v1.

## Build status (2026-08-12, D165)

The build half landed whole. What exists:

- `src/core/symbols/glyphs.ts` — 64 drafted glyphs, four batches,
  canonical append-only order pinned by test. Fill-only paths (M/L/C/Z,
  nonzero winding, holes as reversed contours), so `Path2D` and
  `drawSvgPath` render identical geometry with no stroke config.
- `src/core/symbols/assignment.ts` — the D160-4 model, pure:
  need-based grants in palette order, release-to-back, survivor-free
  replacement resets to canonical, overrides honoured at grant when
  free, `reconcileSymbolState` for loaded files.
- Schema **v6**: `symbols` block (assigned/queue/overrides) +
  `export.chartMode`; migration seeds empty state; round-trip and
  hostile-input tests extended. The ui-baseline `projectJson` pin was
  refreshed for the bump (engine pins untouched).
- Chart modes `color` / `symbols` / `color-symbols` in
  `export/chart.ts` (glyphs drawn per cell, WCAG-luminance ink choice
  over colour) shared by chart PNG and the PDF's embedded raster; the
  PDF key gained a vector symbol column, thread names, and stitch
  counts (name yields to truncation before data does).
- App wiring: `Chart style` select in Chart options, grants at export
  time, refusals for full-RGB, unidentified (reduce-first) output, and
  set exhaustion. Verified live: symbol PNG + PDF export, refusal line.
