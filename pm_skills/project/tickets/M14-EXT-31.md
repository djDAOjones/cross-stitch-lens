# M14-EXT-31 — Preview gets a header; the bar toggle retires

Memo items 6 + 2 (fifth look, D109). One task because the header IS
the replacement collapse route: removing the bar button first would
strand the collapse, adding the header without removing it would
duplicate an affordance (the D90 one-owner rule).

## Outcome

The preview region gains a real section header — **"Preview"**, the
accordion idiom (h2-wrapped toggle button, bare heading when
collapsed per EXT-22) — and collapses from that header. The app bar's
`Hide preview` / `Show preview` button (EXT-23, D107) retires,
superseded on the owner's authority one look later.

## Design points (settle at the gate)

- **Reuse `createSection`** rather than a second header anatomy: the
  preview is not in the settings aside, but the section builder is
  generic and consistency is the point. The existing
  `aria-label="Preview"` landmark should become `aria-labelledby` the
  header so the name is said once.
- **Sticky composition**: the header joins the sticky unit (header ·
  strip · reveal/modal trigger · canvas). Collapsed, only the bare
  heading remains — decide whether a collapsed heading stays sticky
  (recommendation: no; a pinned dead heading is chrome) and prove the
  D103 nothing-scroll-linked rule still holds.
- **State home**: EXT-23 made the collapse session-only shell state.
  As a section, it can join the persisted disclosures like every
  other section — decide at the gate; recommendation: move to the
  disclosure store (`preview-section` key) now that it reads as a
  section, keeping the capture-start re-expand rule either way. If it
  moves, `ShellState.previewCollapsed` dies and (with EXT-32) the
  shell model reduces to `cold` alone.
- **Focus**: collapsing with focus inside hands focus to the header
  (the accordion contract already does this).

## Constraints

- Capture start still re-expands (D107's rule survives the control's
  relocation).
- The frameExists composition stays: no header-only ghost region
  before the first frame — decide whether the header shows pre-frame
  (recommendation: the whole section appears with the first frame,
  exactly as the region does today).
- UI-STANDARDS "the control that reveals a collapsed region lives
  outside it": the accordion header pattern satisfies it (the header
  survives its own collapse) — same argument as every panel section.
