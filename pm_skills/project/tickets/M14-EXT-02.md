# M14-EXT-02 — Source chooser modal

## Outcome

The top-bar Source button opens a Carbon modal (house `modal.ts`)
that names the current source and offers the three routes — Choose an
image · Capture your screen · Try a sample — replacing the in-column
compact source row. Owner feedback triage D88.

## Constraints decided at triage

- **Cold start is untouched**: the first-run entry state (D78/D84)
  remains the preview region's cold content; journey 1 must still
  convert through visible affordances alone (VERIFY-02 re-measures).
  The modal is the *returning* user's switcher.
- **Capture session surfaces stay below the preview** (owner pick):
  thumbnail, crop overlay and pause/lock/stop never live inside the
  modal — the modal closes once a route is chosen; the session then
  runs exactly as today.
- The modal shows the current source line ("Source: my-artwork.png")
  and the capture-expectation sentence with the capture action.
- Drop and paste routes keep working page-wide; the modal names them.
- Focus contract per modal.ts: trap, Escape/backdrop cancel, focus
  returns to the Source button.

## Done when

After a first conversion every source switch flows through the modal;
the compact source row is gone (its information lives in the modal +
existing statuses); cold-start J1 unchanged (1 interaction via
sample/drop, 3 via picker); capture loop byte-for-byte the same
session behaviour; tests + tripwire green; evidence updated.
