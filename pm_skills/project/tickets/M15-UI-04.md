# M15-UI-04 — Editor test preview

Scope parent: D114.

## Slots

1. **The design** (default view) — the last processed still; live
   capture is not re-plumbed into the editor (v1 decision, D114).
2. Photo slots: landscape, cartoon object, portrait, text in three
   fonts — one `<slot>.png` each in a `profile-demo` folder under
   the Vite public root (folder created by this task; the owner
   supplies the files later). A missing file is an intentional
   "Image offline — add `<name>.png` to the profile-demo folder"
   state, distinguished from failed-to-load; the copy carries the
   real path once the folder exists.
3. **The generated test card** (`src/ui/sample.ts`) — can never be
   offline.

## Three-resolution grid

- "Show all at three resolutions": every populated slot at equal
  display size with the stitch grid divided — ÷1, ÷4, ÷16 (the
  divisor is confirmed at build against readability) — so blocks
  grow visibly as resolution drops.
- Renders go through the real pipeline against the draft recipe
  and are draft-labelled (preview is never mistakable for export
  quality — the M4 rule).

## Scheduling

- Debounced (~150 ms) and latest-wins per slot; renders queue
  behind a live session's frames — a running capture's cadence
  must not degrade, and the figures are measured, not assumed.
- Preview canvases repaint on results; editor controls never
  rebuild on frame results (the EXT-43 contract — the pinning test
  lives with UI-02's shell).

## Done when (expanded)

- Slots and grid render against the draft recipe; offline states
  name the missing file and folder; live-session cadence
  unaffected with before/after figures recorded at M15-ACCEPT-01.
